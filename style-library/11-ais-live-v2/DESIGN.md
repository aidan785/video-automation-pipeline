# AIS LIVE v2 — Design Spec

> Evolution of `03-ais-live` for the October VSL wave. Generated by
> `scripts/style-library/gen-ais-live-v2.mjs` — edit the generator, not the
> card files. All 03-ais-live directives (all-blue accents, no em dashes, no
> top strips, no eyebrow marker dots, solid marks, white AIS+) carry over.

## Why v2 exists (Aidan, 2026-09-01)

1. **Cards should tell stories, not just set text.** Enumerated ideas become
   icon rows; comparisons become a versus duel; progressions become a ladder;
   "revenue grows faster than the team" becomes two drawn lines; the AI OS
   becomes a hub diagram; the guarantee becomes a timeline.
2. **Icons in the talky stretches.** `t2-iconpop` is a transparent overlay:
   glass icon chips pop word-synced along the bottom third while the speaker
   stays full-frame ("Sales, Marketing, Operations" moments).
3. **Typography lockups are controlled.** Headline slots accept `<br>` for
   explicit line breaks, and `<em>` accent phrases are wrapped nowrap so
   "AI OS" can never split across lines.

## The icon system

- 24×24 stroke line icons (2.2px, round caps), injected at runtime into any
  `[data-icon="<name>"]` element from the ICONS dict baked into each card.
- Every shape gets `pathLength="100"` → GSAP draws it on with
  `strokeDashoffset: 100 → 0`.
- Chips are liquid glass over an opaque onyx base (`rgba(10,22,35,.92)`) so
  connector lines and video never bleed through, with an inner top highlight,
  blue halo, and a specular sheen sweep after the pop.
- Icon names: compass, doc, megaphone, target, gear, users, userplus, mail,
  bulb, clock, briefcase, building, gradcap, code, scales, heart, spark, flag,
  search, pen, repeat, chartup, rocket, bot, chip, workflow, layers, calendar,
  ticket, check, undo, funnel, bolt, link, globe, down, dollar, key.

## Self-scoping card contract (new in v2)

- Comp ids use dashes (`aisv2-t1-hero`), so every CSS rule is `#<id>`-prefixed
  and every script queries through `ROOT = getElementById("<id>")`. When
  build-beats renames the comp id to `beatNNN`, styles and scripts follow
  automatically — **no post-build script scoping needed**.
- Baked spare rows (`.agrow .crow .vrow .chipwrap .popwrap`) are pruned at
  runtime when their textContent is empty — fills only need to blank them.
- Stat card contract: `countUp("#num", <at>, <target>, <dur>, "<suffix>", "<prefix>")`
  on one line, retargetable by regex from the plan's `stat` slot.
- `t1-thesis-chrome` accepts `data-watermark="<icon>"` on the root for a giant
  faint drawn-on icon behind the type.
- `t2-iconpop` chips carry `data-at="<seconds from beat start>"` — set these
  from word timestamps so each chip lands on its spoken word.
- Standalone preview/screenshot: open the card file with `#t=<seconds>` to
  seek the paused timeline (dev-only hook, inert in builds).
